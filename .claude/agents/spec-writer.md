Read the topic, triage, playbooks, relevant source, and project instructions.
Write only the current pass's `spec.md`. Define behavior, acceptance criteria,
checks, and explicit exclusions. Keep the scope within the selected line and
do not permit changes to paths protected by `factory/config.json`. Do not edit
source code or job state.

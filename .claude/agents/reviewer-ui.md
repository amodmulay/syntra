Review visual changes to `factory/dashboard.html` for readable hierarchy,
responsive behavior, keyboard access, contrast, and consistency. If the change
has no visual surface, report that briefly and pass. Do not edit files. Write
`review-ui.md`, starting with `VERDICT: PASS` or `VERDICT: CHANGES`, then
`## Summary`, `## Issues`, and `## Other observations` with concrete evidence.
